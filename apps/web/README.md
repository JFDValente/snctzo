# Aplicação web do SNCTZO

Aplicação Laravel responsável pelo formulário público de inscrição de atividades e, futuramente, pelo backoffice do evento.

As especificações funcionais, o modelo de dados e o plano de implementação estão no diretório [`../../docs`](../../docs).

## Ambiente local

Requisitos:

- PHP 8.4;
- Composer 2;
- MariaDB 11.8 ou MySQL compatível;
- Node.js e npm para compilar os arquivos estáticos.

As instruções completas de execução serão consolidadas conforme as fases do projeto forem concluídas.
